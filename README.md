# 🐧 MiniOS — Arch Edition

Самодельная операционная система на Python (Tkinter), созданная в качестве хобби-проекта.

## 🚀 Возможности
- **Рабочий стол** с иконками и панелью задач.
- **Терминал** с базовыми командами.
- **Калькулятор** и **Заметки**.
- **Браузер** (открывает ссылки в системном браузере).
- **Лаунчер Minecraft** (через `minecraft_launcher_lib`).
- **Магазин игр** (скачивает инди-игры с GitHub).
- **Пингвинчик Tux**, который говорит случайные фразы (и иногда требует Firefox).
- **Смена тем** (светлая/тёмная) и звуки кликов.
